# Asset notes

All artwork is self-contained SVG. No scripts, remote fonts, external image services or build step are required. The artwork uses explicit backgrounds for light and dark GitHub themes. Typography uses Arial / Helvetica and Courier New fallbacks. Descriptive alt text and native Markdown repeat the essential content.

Professional images are conceptual compositions, not product screenshots, architecture diagrams or telemetry. No private repository was accessed.
