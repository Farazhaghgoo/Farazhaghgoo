## 02 / Selected builds

### [Whomst ↗](https://github.com/Farazhaghgoo/whomst)
**A personality quiz with a scoring engine underneath.**

Character matching across 12 trait dimensions, with server-side scoring and shareable result pages.

**A decision that matters:** keep scoring on the server while making the result easy to share through dynamically generated preview images.

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Redis` `Vitest`

### [Ledger ↗](https://github.com/Farazhaghgoo/financeApp)
**Personal finance for the money automation misses.**

A mobile app for cash spending, income, and peer transfers, with optimistic updates and offline-tolerant writes.

**A decision that matters:** model transfers separately from expenses. Moving money should not look like spending it.

`React Native` `Expo` `TypeScript` `Supabase` `TanStack Query`

### [AI Career Partner ↗](https://github.com/Farazhaghgoo/CVai)
**An interface experiment for AI-assisted job searching.**

A UI prototype exploring CV feedback, job matching, and career insights using mock data, custom SVG charts, and animated interactions.

`React` `Vite` `Tailwind CSS` `SVG`

### [VeloCity ↗](https://github.com/Farazhaghgoo/VeloCity)
**A study in motion, information, and trust.**

A landing-page experience for data-verification and data-room workflows, with animated interactions and a waitlist backend.

`Next.js` `React` `TypeScript` `Tailwind CSS` `GSAP` `Framer Motion`
