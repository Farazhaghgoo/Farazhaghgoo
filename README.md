## 🧩 How I Think About Software

I care about more than making something compile.

**Product thinking** — What problem is this actually solving?

**Architecture** — Will it still make sense when the project grows?

**UX** — Does the user understand what to do without being told?

**Security** — Where does sensitive information live and who can access it?

**Details** — Does the interaction feel intentional?

**Experimentation** — Can a strange idea become a useful product?
