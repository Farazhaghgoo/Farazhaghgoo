# Design and sources

This profile was redesigned using [beautify-github-profile](https://github.com/rzashakeri/beautify-github-profile) as the reference collection: animated introductions, recognizable skill icons, compact project cards and activity visuals.

## Original work

The orbital wireframe hero, professional-work illustrations (`scripts/source/work-*.svg`, nested into the work cards), project cards, intro, buttons, section labels, project marquee, toolkit panel, footer and control-room renderer were created for this profile.

The pickup ticket beside the HamiYami phone, the UniExamer question, the VibeAssist chart and advisor, the edbub podium and medal, and every other cover element are conceptual artwork, not screenshots.

## Content verification

Public project descriptions were checked against these repository READMEs and manifests.

On 10 November 2026:

- [HamiYami](https://github.com/Farazhaghgoo/hamiYami). The test counts (117 unit, 51 browser) are the ones its README reported on that date; update the profile if they change. [hamiyami.com](https://hamiyami.com) answered on that date. HamiYami is a prelaunch demo: every meal, cook and availability figure in it is fictional.

On 11 November 2026, both built with [AMIRAK-code](https://github.com/AMIRAK-code), whose account owns the repositories:

- [UniExamer](https://github.com/AMIRAK-code/EXAMassist), the `EXAMassist` repository; its README names the product and the uniexamer.com domain. [uniexamer.com](https://uniexamer.com) answered on that date.
- [VibeAssist](https://github.com/AMIRAK-code/vibeassist). [vibeassist.assist365.app](https://vibeassist.assist365.app) answered on that date.

edbub is a hackathon team project in a private repository, so its banner says only what the profile owner stated: third place, built with friends. No source was read and nothing else is claimed.

The side projects listed in the strip under the banner (curseek, portfolio, Whomst, Ledger, VeloCity and CVai) are links only.

The professional-work context and LinkedIn address come from the supplied conversation. Professional source code was not accessed.

The control room’s totals come directly from the [public GitHub contribution calendar](https://github.com/users/Farazhaghgoo/contributions), private contributions included. It combines that calendar with two other public sources: the commit search API, for commits by this account in any public repository (including [EXAMassist](https://github.com/AMIRAK-code/EXAMassist) and [vibeassist](https://github.com/AMIRAK-code/vibeassist)), and the profile’s public day view, for the number of private contributions per day. `assets/contributions.json` keeps the data behind the image for reproducibility. Private work is present only as those daily counts, which the profile already shares; private repository names, commit messages, code and implementation details are neither requested nor stored.
