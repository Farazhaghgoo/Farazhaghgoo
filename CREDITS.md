# Design and sources

This profile was redesigned using [beautify-github-profile](https://github.com/rzashakeri/beautify-github-profile) as the reference collection: animated introductions, recognizable skill icons, compact project cards and activity visuals.

## Included third-party assets

- [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg), by Jonah Lawrence: the locally saved `assets/typing.svg`. MIT license in `licenses/readme-typing-svg.txt`. Generated with three custom lines about engineering, products and Turin; orange text on a transparent background.
- [Fira Code](https://github.com/tonsky/FiraCode), embedded in the typing SVG. SIL Open Font License in `licenses/FiraCode.txt`.
- [Skill Icons](https://github.com/tandpfun/skill-icons), by tandpfun: the locally saved `assets/skill-icons.svg`. MIT license in `licenses/skill-icons.txt`. Technology marks belong to their respective owners; inclusion does not imply endorsement.

## Original work

The orbital wireframe hero, professional-work illustrations, project covers, section labels, contact buttons, footer and contribution-landscape renderer were created for this profile. The activity landscape takes inspiration from the 3D calendar idea in [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib); it does not use or copy that project's generator.

## Content verification

Public project descriptions were checked against these repository READMEs and manifests on 24 September 2026:

- [Whomst](https://github.com/Farazhaghgoo/whomst)
- [Ledger / financeApp](https://github.com/Farazhaghgoo/financeApp)
- [VeloCity](https://github.com/Farazhaghgoo/VeloCity)
- [CVai](https://github.com/Farazhaghgoo/CVai)

The professional-work context and LinkedIn address come from the supplied conversation. CVai is described as a prototype with mock data. Professional source code was not accessed. All project-cover interface elements are conceptual artwork.

Activity comes directly from the [public GitHub calendar](https://github.com/users/Farazhaghgoo/contributions). The included JSON retains dates, levels and public counts for reproducibility. Private repository names, code and implementation details are neither requested nor stored.
