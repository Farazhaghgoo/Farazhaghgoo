# Design and sources

This profile was redesigned using [beautify-github-profile](https://github.com/rzashakeri/beautify-github-profile) as the reference collection: animated introductions, recognizable skill icons, compact project cards and activity visuals.

## Original work

The orbital wireframe hero, professional-work illustrations, project covers, section labels, contact buttons, project marquee, footer, contribution-landscape renderer and ship-log renderer were created for this profile. The activity landscape takes inspiration from the 3D calendar idea in [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib); it does not use or copy that project's generator.

The curseek cover is a maze generated by `scripts/build_art.py`, with one scripted round per loop: reveal, lights out, hunt, catch. It illustrates the game's rules; it is not a recording of the game. The pickup ticket beside the HamiYami phone, the Portfolio command line and every other cover element are conceptual artwork.
