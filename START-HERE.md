# Publish your profile

The `Farazhaghgoo` folder contains the ready-to-push contents for `Farazhaghgoo/Farazhaghgoo`.

1. Open your local clone of that repository, or use GitHub’s upload-files interface.
2. Copy `README.md`, `ASSET-NOTES.md` and the entire `assets` folder into the repository root. Replace the existing README. Keep other unrelated repository files.
3. Commit and push to the default branch (`main`). The repository must be public for the profile README to appear.

Do not place the outer `Farazhaghgoo` folder inside the repository. The correct paths are `README.md` and `assets/hero.svg`, not `Farazhaghgoo/README.md`.

Open `Preview.html` beside the `Farazhaghgoo` folder to see a local approximation of the README. GitHub controls the surrounding typography and spacing; the custom SVG panels retain their own design. No hosting, dependencies, tokens or build commands are required.

The package has 12 rendered and inspected SVG assets. All 12 relative image links resolve with exact filename case. All SVGs parse as XML and contain no scripts, embedded web pages, remote fonts or external resources. The four public repository destinations were confirmed via GitHub.
